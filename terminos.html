Condiciones del Servicio

Asistente IA Oscar

Última actualización: septiembre de 2026

1. Finalidad del servicio

Asistente IA Oscar es un proyecto educativo y experimental desarrollado con fines de aprendizaje, demostración y evaluación de tecnologías de Inteligencia Artificial, automatización y comunicación mediante WhatsApp Cloud API.

2. Uso del asistente

El usuario puede interactuar voluntariamente con el asistente mediante mensajes enviados a través de los canales habilitados para el proyecto. El contenido enviado podrá ser procesado automáticamente para generar una respuesta relacionada con la solicitud realizada.

3. Respuestas generadas mediante Inteligencia Artificial

Algunas respuestas pueden ser generadas automáticamente mediante modelos de Inteligencia Artificial. Debido a la naturaleza de estas tecnologías, las respuestas pueden contener errores, información incompleta o interpretaciones incorrectas.

El usuario deberá verificar la información cuando esta sea relevante para la toma de decisiones.

4. Limitaciones

El asistente tiene carácter educativo y experimental. Sus respuestas no sustituyen asesoramiento profesional especializado, incluyendo asesoramiento médico, jurídico, financiero o de seguridad.

5. Disponibilidad

El servicio puede ser modificado, suspendido o interrumpido temporalmente como consecuencia de pruebas, mantenimiento, cambios tecnológicos o disponibilidad de los servicios utilizados por el proyecto.

6. Uso adecuado

El usuario se compromete a utilizar el servicio de manera responsable y a no emplearlo para actividades ilícitas, abusivas o destinadas a afectar el funcionamiento de los sistemas involucrados.

7. Servicios de terceros

El funcionamiento del proyecto puede depender de servicios y plataformas de terceros, incluyendo WhatsApp Cloud API de Meta Platforms y otras herramientas tecnológicas necesarias para la comunicación y procesamiento de información.

8. Privacidad

El tratamiento de información relacionado con el uso del asistente se describe en la Política de Privacidad del proyecto.

Las instrucciones relacionadas con solicitudes de eliminación de datos se encuentran disponibles en la sección correspondiente de este sitio.

10. Modificaciones

Estas condiciones podrán actualizarse conforme evolucione el proyecto, se incorporen nuevas funcionalidades o cambien los requisitos de los servicios utilizados.

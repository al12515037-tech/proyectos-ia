Política de Privacidad

Asistente IA Oscar

Última actualización: septiembre de 2026

1. Descripción del proyecto

Asistente IA Oscar es un proyecto educativo y experimental orientado al aprendizaje y desarrollo de soluciones de Inteligencia Artificial, automatización y comunicación mediante WhatsApp.

El proyecto utiliza WhatsApp Cloud API para recibir y enviar mensajes y puede utilizar modelos de Inteligencia Artificial para generar respuestas automatizadas.

2. Información procesada

Cuando un usuario envía voluntariamente un mensaje al asistente, el sistema puede procesar información técnica necesaria para la comunicación, incluyendo el número asociado a WhatsApp, el contenido del mensaje y datos técnicos proporcionados por la plataforma para gestionar la conversación.

3. Finalidad del tratamiento

La información recibida se utiliza exclusivamente para procesar los mensajes enviados por el usuario, generar una respuesta mediante el asistente y realizar pruebas técnicas relacionadas con el desarrollo y funcionamiento del proyecto.

4. Inteligencia Artificial

Los mensajes pueden ser procesados mediante modelos de Inteligencia Artificial con el propósito de interpretar la solicitud del usuario y generar una respuesta automatizada.

Las respuestas generadas automáticamente pueden contener errores y no deben considerarse asesoramiento profesional, médico, jurídico, financiero ni de otra naturaleza especializada.

5. Servicios de terceros

Para proporcionar determinadas funciones, el proyecto puede utilizar servicios tecnológicos de terceros, incluyendo WhatsApp Cloud API de Meta Platforms y herramientas necesarias para la comunicación, alojamiento o procesamiento técnico.

Dichos servicios pueden procesar información conforme a sus propias políticas de privacidad y condiciones de servicio.

6. Conservación y seguridad

Se procura limitar el tratamiento de información a lo necesario para el funcionamiento, prueba y mejora técnica del proyecto. Asimismo, se aplican medidas razonables para evitar accesos no autorizados a la información procesada.

7. Eliminación de datos

Los usuarios pueden solicitar información sobre la eliminación de datos relacionados con su interacción con el proyecto mediante la página de Eliminación de Datos disponible en este sitio.

Consultar instrucciones para eliminación de datos

8. Cambios en esta política

Esta Política de Privacidad podrá actualizarse cuando se incorporen nuevas funciones, tecnologías o requisitos aplicables al proyecto. La versión vigente será publicada en esta página.

9. Contacto

Para consultas relacionadas con esta Política de Privacidad puede utilizarse el correo electrónico de contacto registrado para la aplicación Asistente IA Oscar.
